- 목표명
- 세부목표를 칩으로 나열 (예: 단어 · LC · RC). 반복 세부목표 칩에는 작은 "매일" 표시

- 상태: 시작 전 / 진행 중
- 세부목표가 하나도 없으면 "세부목표를 추가해 주세요" 안내를 흐리게 표시
현재 카드 불릿에 섞여 있는 기한·설명 문장은 카드에서 빼고 편집 패널로 옮겨 주세요.

## 2. 카드를 클릭하면 — 오른쪽 편집 패널
보드는 왼쪽에 그대로 보이고, 오른쪽에서 패널이 열려요. 선택된 카드는 테두리로 강조. 패널을 연 채로 다른 카드를 누르면 그 목표로 바뀌어요.

패널 구성 (위에서 아래로)
1) 목표명, 카테고리 (드롭다운)
2) 목표의 특성
   - 기한 (필수)
   - 이유: 이 목표를 왜 이루고 싶은지 (선택)
   - 중요도: 높음 / 보통 / 낮음 (선택)
   - 대안: 잘 안 될 경우의 플랜 B (선택, 예: "안 되면 CPU만")
3) 세부목표 목록 — 패널의 중심 영역
   - 한 줄에 세부목표 하나: 이름 + "매일 반복" 토글 + 순서 변경 핸들 + 삭제
   - "+ 세부목표 추가" 입력 칸 (Enter로 연속 추가)
   - 계획 표에 이미 배치된 세부목표는 삭제 대신 "계획 표에 배치됨" 표시, 삭제 버튼 비활성
4) 패널 하단: 시작 전인 목표에만 "목표 삭제" 텍스트 버튼

## 3. 반복(매일) 세부목표
세부목표에 "매일 반복" 속성을 켤 수 있어요. 예: 토익 → "매일 단어 40개", 독서 → "매일 30쪽 읽기", 건강 → "매일 운동", 생활 → "매일 청소".
- 꿈 보드 칩과 계획 표 칸에 "매일" 표시가 붙어요
- 계획 표에서는 기간(여러 달·여러 주)에 걸친 병합 칸으로 배치하는 것이 기본이에요
- 샘플 데이터에 반복 세부목표를 2~3개 넣어 주세요

## 4. 계획 표 칸 입력 동작 (연간·월간·주간 공통)
- 계획 표 칸에는 세부목표만 넣을 수 있어요
- 빈 칸을 누르면 그 열(목표)의 세부목표 목록이 팝오버로 떠요. 하나를 고르고, 그 칸에서 할 내용을 짧은 메모로 적어요
  - 예: 토익 열 · 10월 칸 → 세부목표 "단어" + 메모 "단어장 1회독"
- 칸 표시: 메모를 크게, 세부목표 이름을 작은 칩으로 위에. 메모가 없으면 세부목표 이름만
- 세부목표가 0개인 목표는 열로 추가할 수 없어요. "+ 목표 열"에서 흐리게 표시하고 "꿈 보드에서 세부목표를 먼저 추가해 주세요" 안내
- 꿈 보드에서 세부목표 이름을 바꾸면 계획 표 칸의 칩에도 반영돼요

- 사이드 앱 '모아' — 기한 27.02 / 세부목표: 기획, 디자인, 개발, 출시
