## 1. "반복" 개념 전체 삭제

- 세부목표 이름에 "매일 단어 40개"처럼 반복의 느낌을 담는 건 사용자 자유예요. 이름일 뿐 특별한 동작은 없어요.

## 2. 계획 표 열 구조

# PhD Desktop v2 — 계획 표 3종 역할 분리

이번 수정 범위는 연간·월간·주간 계획 표뿐이에요. 꿈 보드와 다른 화면은 그대로 두세요.

## 용어 (모든 화면에서 통일)
- 목표: 계획 표의 열 (예: 토익 850)
- 세부목표: 목표 아래 단위 (예: 단어, LC, RC). 꿈 보드에서 만들어요
- 실천: 주간 표에서 쓰는 구체적인 행동 (예: "매일 단어 40개", "LC 교재 2장"). 하나의 세부목표에 속하고, 모바일의 할 일이 돼요
- 실천에는 "반복" 또는 "단발" 속성이 있어요

## 세 표의 역할
| 표 | 칸에 들어가는 것 | 역할 |
| 연간 | 세부목표 + 짧은 메모 | 어느 달에 어떤 세부목표를 할지 큰 배치 |
| 월간 | 세부목표 + 코멘트 | 이번 달 사정에 맞춰 주차별로 재배분 |
| 주간 | 실천 여러 개 | 이번 주에 실제로 할 일 작성 |
각 표 상단 설명 문구도 이 역할에 맞게 바꿔 주세요.

## 1. 연간 표
- 지금 구조를 유지해요. 칸 = 세부목표 칩 + 짧은 메모
- 월간에서 바꾼 내용은 연간에 자동 반영되지 않아요. 연간은 "처음 계획"으로 남아요

## 2. 월간 표
- 행은 주차, 칸 = 세부목표 칩 + 코멘트 (예: "LC" + "3주차 훈련이라 4주차에 몰아서")
- 맨 위 "상위 계획" 줄에 연간 표의 이번 달 칸이 내려와 있는 지금 구조 유지
- 빈 칸 팝오버: 그 목표의 세부목표 전체를 보여 주되, 연간 표에서 이번 달에 배치한 세부목표를 맨 위에 "이번 달 계획" 표시와 함께 강조
- 샘플에 "연간 계획과 다르게 조정한" 칸을 1~2개 넣어 주세요 (상위 계획 줄과 비교되게)

## 3. 주간 표 — 가장 크게 바뀌는 부분
- 맨 위 "상위 계획" 줄에 월간 표의 이번 주 칸(세부목표 + 코멘트)이 내려와 있는 구조 유지
- 칸 하나에 실천을 여러 개 넣을 수 있어요. 실천 하나 = 작은 카드 한 줄:
  세부목표 칩 + 실천 이름 + 속성 표시 ("반복"이면 작은 ↻ 아이콘, 단발이면 표시 없음)
- 빈 칸(또는 칸 안의 "+")을 누르면 팝오버:
  1) 세부목표 선택 (상위 계획 줄에 있는 세부목표를 위에 강조)
  2) 실천 이름 입력
  3) 반복 / 단발 선택 (기본값 단발)
- 칸 병합은 "기간"만 뜻해요. 반복 여부는 실천의 속성이 정해요
- 표 하단 안내 문구:
  "반복 실천은 그 기간 동안 매일 할 일로 나타나요. 단발 실천은 한 번 완료하면 사라지고, 하루짜리 칸의 단발 실천은 못 하면 다음 날로 넘어가요."
- 칸이 좁아지므로, 실천이 3개를 넘으면 "+2개 더"로 접어 주세요

## 샘플 데이터 (10월 1주차, 토익 850 열 예시)
- 월~일 병합 칸: [단어] 매일 단어 40개 ↻
- 화: [LC] Part 1 사진
- 목: [LC] Part 2 응답
- 수~금 병합 칸: [RC] 문법 파트 정리 (단발, "이번 주 중 한 번")
다른 목표 열도 같은 방식으로 반복 실천 1개 + 단발 실천 몇 개가 섞이게 채워 주세요.

# PhD Desktop v2 — 주간 표 구조 수정

이번 수정 범위는 주간 계획 표뿐이에요. 연간·월간 표와 다른 화면은 그대로 두세요.

## 문제
지금 주간 표는 기간 있는 실천(월~일, 수~금)과 하루짜리 실천이 같은 열에 섞여서, 열 하나가 여러 세로 줄로 쪼개지고 글자가 잘려요.
목표: 어떤 경우에도 "목표 열 하나 = 세로 한 줄"로 고정.

## 1. 표 구조 (위에서 아래로)
1) 열 머리: 목표명 (지금과 같음)
2) "상위 계획" 줄: 월간 표의 이번 주 칸이 내려와 있는 지금 구조 유지
3) "이번 주" 줄 (새로 추가): 기간이 있는 실천을 모아 두는 줄
4) 요일 줄 7개 (월~일): 하루짜리 실천만

## 2. "이번 주" 줄
- 기간이 있는 실천을 열마다 목록으로 쌓아요. 반복이든 단발이든 기간이 하루보다 길면 여기에 들어가요
- 실천 한 줄: 세로목표 칩 + 실천 이름 + 반복이면 ↻ 아이콘 + 오른쪽에 요일 표시
- 이 줄의 높이는 내용에 맞게 늘어나되, 실천이 3개를 넘으면 "+N개 더"로 접어요
- 줄 앞(행 머리)에 "이번 주" 라벨과 작은 설명: "여러 날에 걸친 실천"

## 3. 요일 칸
- 하루짜리 실천만 들어가요. 여러 개면 위아래로 쌓아요 (가로로 나누지 않음)
- 실천이 3개를 넘으면 "+N개 더"로 접어요
- 주간 표에서는 칸 병합을 없애요. (단, "일과" 열은 지금처럼 병합 유지)

## 4. 요일 칩 (실험 기능)
실천을 추가하는 팝오버에서:
1) 세부목표 선택 (상위 계획 줄에 있는 세부목표를 위에 강조)
2) 실천 이름 입력
3) 반복 / 단발 선택 (기본값 단발)
4) 요일 칩 7개 (월 화 수 목 금 토 일) — 여러 개 선택 가능

empty는 방금 가입을 마친 사용자의 상태예요. 샘플 데이터를 하나도 넣지 말고, 모든 입력·추가 동작은 실제로 동작하게 해 주세요.

## 가입 직후 상태
- 가입에서 고른 카테고리(예: 3개 + 일상)만 있고, 목표·세부목표·계획·기록은 없음
- 궁극적 꿈은 건너뛴 상태

## 화면별 빈 상태 안내 (한 줄 설명 + 다음 행동 버튼 하나)
- 목표 설정: "카테고리마다 이루고 싶은 목표를 적어 보세요"
- 꿈 보드: 목표가 없으면 "먼저 목표를 적어 주세요 → 목표 설정", 목표는 있는데 세부목표가 없으면 카드마다 "세부목표를 추가해 주세요"
- 연간 표: 열이 없으면 "꿈 보드에서 세부목표를 만든 목표만 열로 추가할 수 있어요"
- 월간 표: 상위 계획 줄이 비어 있으면 "연간 표의 이번 달 칸이 여기로 내려와요"
- 주간 표: 상위 계획 줄이 비어 있으면 "월간 표의 이번 주 칸이 여기로 내려와요"
- 트래킹: "모바일에서 시간을 칠하면 여기에 쌓여요"
- 회고 모음: "마무리한 목표의 회고가 여기에 모여요"
- 모바일 오늘: 반복·오늘 할 일 모두 비어 있으면 "데스크톱 주간 표에서 실천을 적으면 여기에 나타나요" + "+ 직접 추가"는 사용 가능

## 진행 안내
데스크톱 사이드바 상단에 시작 체크리스트를 작게 표시하고, 다 마치면 사라지게:
목표 적기 → 세부목표 만들기 → 연간 표에 배치 → 월간 조정 → 주간 실천 적기 → 모바일에서 첫 기록

- **empty 상태:** 커리어·어학·건강 카테고리와 일상만 있고, 꿈은 건너뛴 상태예요. 목표·세부목표·계획·기록은 하나도 없고, 입력과 추가는 실제로 동작해요.

  - 목표 설정은 "첫 목표 적기", 꿈 보드는 "목표 설정"으로 이어져요.
  - 연간·월간·주간 표에 목표 열이 없으면 "+ 목표 열 추가" 또는 "꿈 보드로" 버튼이 보여요. 세부목표가 있는 목표가 있는지에 따라 바뀌어요.
  - 월간·주간 표의 상위 계획 줄이 비면 그 줄 안에 안내 문구가 보여요.
  - 트래킹은 "주간 실천 적기", 회고 모음은 "꿈 보드" 버튼으로 이어져요.
- **시작 체크리스트:** 데스크톱 사이드바 위에 여섯 단계가 있어요. 끝낸 단계는 체크되고 다음 단계가 강조돼요. 단계를 누르면 그 화면으로 가요.
- **모바일 empty:** 반복과 오늘 할 일이 모두 비면 "데스크톱 주간 표에서 실천을 적으면 여기에 나타나요"가 보이고, "+ 직접 추가"는 그대로 쓸 수 있어요. 목표가 없어서 D-day 배지는 숨겼어요.

알아 두실 점이 있어요.
- 데스크톱만으로는 모바일 기록을 알 수 없어서, empty에서는 "모바일에서 첫 기록" 단계가 끝나지 않아요. 그래서 체크리스트가 계속 남아 있고, sample에서는 모두 끝난 상태라 보이지 않아요.
- 데스크톱의 시작 화면(startScreen)은 여전히 로그인이 기본이에요.

# PhD Mobile — 10분 시간표 표현 방식 변경 (종이 스터디 플래너 느낌)

이번 수정은 시간표를 "그리는 방식"만 바꿔요. 칠하기 로직(144칸 배열, 형광펜 드래그, 모드 전환)과 다른 영역은 그대로 두세요.

## 1. 격자
- 10분 칸마다 떨어진 둥근 타일을 없애고, 종이처럼 얇은 선으로 나뉜 연속 격자로
- 칸 사이 gap 0, 모서리 없음. 1시간 줄 사이 선은 조금 진하게, 10분 칸 사이 선은 아주 연하게
- 30분 위치(3칸째 뒤)에 점선 하나

## 2. 블록은 칸이 아니라 "구간"으로 그리기
- 각 층(계획/실제) 배열에서, 한 시간 줄 안의 연속된 같은 값의 칸을 하나의 구간으로 묶어요
- 구간마다 도형 하나를 같은 grid 위에 얹어요 (grid-row = 그 줄, grid-column = 시작 / span 칸수)
- 여러 줄에 걸친 블록은 줄마다 도형 하나씩. 이름·번호는 첫 줄 도형에만

## 3. 계획 = 테두리 네모
- 회색 1.5px 테두리 + 아주 옅은 회색 배경, 모서리 살짝 둥글게(4px)
- 이름은 도형 안 왼쪽에 작게(10px), 한 줄, 넘치면 말줄임
- 예약 할 일: 이름 앞에 알람 아이콘
- 구간이 2칸(20분) 이하면 이름 생략

## 4. 실제 = 형광펜 칠
- 카테고리 색을 반투명(약 55%)으로 채운 띠. 테두리 없음
- 위아래로 약간 여백을 둬서(칸 높이의 70% 정도) 형광펜으로 그은 느낌
- 계획 테두리 네모보다 아래 층에 그려서, 겹치면 테두리가 칠 위로 보이게

## 5. 번호
- 할 일 목록의 항목마다 왼쪽에 번호(1, 2, 3…). 반복 섹션과 오늘 할 일 섹션을 이어서 매김
- 실제 칠 구간의 시작 부분에 그 할 일 번호를 작은 동그라미(지름 14px, 카테고리 색 테두리)로 표시
- 일상 키워드로 칠한 구간은 번호 대신 키워드 첫 글자 (업, 생, 이, 휴)
- 한 줄 안에서 이어지는 다음 줄 도형에는 번호를 반복하지 않음

## 6. 확인용 샘플
- 계획과 실제가 부분적으로 겹치는 구간 2~3곳
- 1시간 넘게 이어져 여러 줄에 걸친 실제 칠 1곳
- 10분짜리 짧은 계획 블록 1곳 (이름 생략 확인용)

시간표를 종이 스터디 플래너처럼 보이게 바꿨어요. 칠하는 동작은 그대로이고, 지금 별도 검토가 돌고 있어요.

- **격자:** 칸 사이 간격 없이 얇은 선으로 나눴어요. 1시간 줄 사이 선은 조금 진하고, 10분 칸 사이 선은 아주 연해요. 30분 위치에는 점선이 하나 들어가요.
- **계획:** 한 줄 안에서 이어지는 칸을 회색 테두리 네모 하나로 그려요. 이름은 블록의 첫 줄에 한 번만 보여요.
  - 할 일과 연결된 블록은 이름 앞에 카테고리 색 점이, 예약 할 일은 알람 아이콘이 붙어요.
- **실제:** 카테고리 색을 반투명하게 칠한 형광펜 띠예요. 위아래에 여백이 있고, 계획 테두리보다 아래에 깔려요.
- **번호:** 할 일 목록 왼쪽에 반복부터 오늘 할 일까지 이어지는 번호를 붙였어요. 실제 칠의 시작 부분에 그 번호가 작은 동그라미로 보이고, 일상 키워드로 칠한 곳은 첫 글자(이·휴 등)가 보여요. 다음 줄로 이어지는 부분에는 반복하지 않아요.
- **샘플:** 10분짜리 계획 블록 "휴식"(14:20)과 키워드 칠 "이동"(13:50–14:20)을 더했어요. 여러 줄에 걸친 실제 칠은 사용자 인터뷰(10:30–12:00)이고, 계획과 실제가 부분적으로 겹치는 곳도 여럿 있어요.

알아 두실 점이 있어요.
- 블록 첫 줄이 2칸 이하이면 이름을 생략하라는 규칙대로면, :50에 시작하는 블록은 이름이 아예 사라져요. 그래서 이런 경우에는 3칸 이상인 다음 줄에 이름을 넣었어요.
- `data` 기본값이 empty라서, 샘플 시간표는 Tweaks에서 `data`를 sample로 바꿔야 보여요.

계획 블록 이름이 실제 칠의 번호 동그라미를 가리던 문제를 고쳤어요. 페이지는 콘솔 오류 없이 열려요.

- **동그라미 위치:** 번호 동그라미를 칠 띠에서 떼어 계획 네모보다 위에 그리도록 바꿨어요. 칠 띠가 맨 아래, 계획 테두리가 그 위, 번호가 맨 위 순서예요.
- **이름 밀기:** 계획 블록의 이름이 시작하는 칸에 번호가 있으면, 이름을 18px 오른쪽으로 밀어서 둘이 겹치지 않아요.

다만 번호가 계획 블록의 첫 칸이 아니라 중간에 있으면, 긴 이름 글자 위에 동그라미가 얹힐 수 있어요.
