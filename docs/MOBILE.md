# 모바일 통합 (v2) — 계획과 결정

2026-10-02 기획 요청: 데스크톱 + 모바일로 나뉜 서비스를 **모바일 하나로** 쓸 수 있게 만든다.

- **생김새** 기준: `design-reference/PhD only for Mobile v2.dc.html` (Claude Design 목업)
- **기능** 기준: 지금까지 만든 데스크톱·모바일 기능과 `docs/SPEC.md` 규칙 (기획 지시: "기능은 기존, 디자인은 목업")
- 데스크톱 화면은 그대로 둔다 (백업). **화면 폭 768px 미만 = 새 모바일 앱**, 넓은 화면 = 지금까지의 데스크톱 (2026-10-02 기획 결정)
- 정보는 적게, 한 화면에 한 가지 일 — 모바일의 좁은 폭을 장점으로 (기획 요청)
- 단계별 중간 보고 없이 끝까지 만든 뒤 한 번에 검수 (2026-10-02 기획 결정)

## 화면 구조

```
앱바: [PhD 로고]            [계획 | 기록]  (내 이니셜 → 계정 시트)
계획 ─ 목표: 시작하기(5단계) · 나의 꿈 · + 목표 추가 · 카테고리별 목표(진척도 막대) · 마무리한 목표
     └ 일정: 연간 / 월간 / 주간 + 목표 필터, 줄 = 달 / 주 / 요일
기록 ─ 오늘: 할 일 + 10분 시간표 + 하루 기록 (기존 하루 플래너)
     └ 돌아보기: 이번 주·이번 달 숫자, 목표별 시간, 하루 점수 달력
오른쪽에서 밀려 들어오는 화면: 목표 편집, 카테고리, 꿈, 설정
아래에서 올라오는 시트: 새 목표, 마무리, 회고, 계획 칸, 실천, 참고사항, 직접 추가, 계획 블록, 하루 기록, 계정
```

주소: `/plan`(목표) `/plan/schedule?z=year|month|week&k=…&f=목표`(일정) `/record?d=날짜`(오늘) `/record/review?r=week|month&k=…`(돌아보기) `/goal/:id` `/categories` `/dream` `/settings`.
시트는 열 때 기록(history)에 한 칸을 넣어, 휴대폰 뒤로 가기로 닫힌다. 위쪽 회색 손잡이를 끌어내려도 닫힌다(많이 또는 빠르게 내리면 닫히고, 조금만 내리면 제자리로, 톡 눌러도 닫힘 — 2026-10-03 기획 요청).

## 목업과 다른 점 (기존 기능·결정을 따른 것)

| 목업 | 이번 구현 | 근거 |
|---|---|---|
| 실천 '방식' (요일마다 반복 / 이번 주 한 번) | 없음. 요일 1개 = 단발(넘어감), 여러 개 = 반복 | 2026-10-01 기획 결정 (R-P7) |
| 목표 카테고리 색 고르기 | 순서대로 자동. 일상 색만 고름 | R-C1 |
| 연간 계획이 해를 넘김 ('이어짐') | 해·달을 넘겨 고르면 해(연간)·달(월간)마다 나눠 저장 (R-P15) | 2026-10-03 기획 결정 |
| 기간 고르기: 시작 칸 + 길이 −/+ | 시작·끝 드롭다운 | 2026-10-03 기획 결정 |
| 계획 칸에서 목표 자유 선택 | 위 계획에서 먼저 고르기, 그 밖은 한 번 더 + '계획 밖' 표시 (R-P14) | 2026-10-03 기획 결정 |
| 여러 기간 계획은 첫 줄에만 | 걸친 줄마다 (다음 줄은 '이어짐') | 2026-10-03 기획 결정 |
| 빈 줄을 눌러 바로 추가 | 없음. '+ 계획 / + 실천'으로만 | 2026-10-03 기획 결정 |
| 목표 편집 '일정에서 보기' | '작성 완료' | 2026-10-03 기획 결정 |
| 가입 3단계 추천 칩 | 시기 템플릿(삶의 수레바퀴)을 미리 골라 둠 (R-C5) | 2026-10-03 기획 결정 |
| 실천 고치기 | 보기 + 지우기 (지난 날이 없을 때). 고치려면 지우고 다시 | 기존 DB 규칙 (실천은 추가·삭제만) |
| 계획 칸에서 목표·세부목표 바꾸기 | 기간·메모만 고침. 다른 세부목표는 지우고 다시 | 기존 DB 규칙 |
| 하루 기록: 점수·이유·메모 | 감사 세 줄도 그대로 | R-J2 |
| 돌아보기에 진척도·누적 시간 없음 | 진척도 슬라이더와 누적 시간은 **목표 편집** 화면으로 | 목업(진척도) + 기존 기능 유지 |
| 참고사항 만드는 곳 없음 | 일정 '+ 계획 / + 실천' 시트에서 '참고사항'을 고르면 적을 수 있음 | 기존 기능 유지 |
| Google 로그인 버튼 | 없음 | SPEC 5장 (나중에) |
| 회원가입 1단계에서 바로 4단계까지 화면 안에서 | 그대로 (계정 → 시기 → 카테고리 → 꿈) | 기존 |
| 하루 플래너 앱바의 D-day | 계획 › 목표에서 하나 정하고(이름 + 날짜), '오늘·돌아보기' 탭 줄 오른쪽에 작게 | R-S10, 2026-10-03 기획 결정 |
| 반복 섹션 '다음 날로 넘어가지 않아요' | 없앰 | 2026-10-03 기획 결정 |
| 지난날·보기 전용 날의 안내 줄 | 없앰. 날짜 옆 배지에 자물쇠, 누르면 안내 — 날마다 레이아웃이 같게 | 2026-10-03 기획 결정 |
| 계정 시트: 시기·카테고리·꿈·로그아웃 | + **설정** 화면(이름, 시기, 하루 시작 시간, 테마, 회고 알림, 내보내기, 비밀번호, 계정 삭제) | 기존 계정 관리 기능 |

시작하기 체크리스트(모바일): **체험해 보기** → 꿈 한 문장 → 첫 목표 → 세부 목표 → 이번 주 실천 → 오늘 첫 기록(할 일 체크 또는 시간 칠하기). 모두 마치면 사라짐 (2026-10-02 목업의 5단계 + 2026-10-03 체험 모드).

체험 모드(`/tutorial`, 2026-10-03 기획 결정): 예시 목표 '책 2권 읽기'로 목표 → 세부 목표 → 연간(같은 달에 두 번째 세부 목표를 넣으면 '한 기간에는 목표마다 칸 하나' 강조 — 2026-10-05부터 세부 목표는 한 칸에 여러 개, R-P17) → 월간(연간에서 고르기) → 주간(월간에서 고르기) → 오늘(체크·칠하기) → 마무리. 화면 안에서만 움직이고 계정에 저장하지 않는다. 끝내면 새 목표 시트가 열린다. 마쳤는지는 이 기기에 기억(`localStorage phd-tutorial-done`).

계획 연결(2026-10-03 기획 논의): 데스크톱도 연간·월간·주간 연결을 강제하지는 않고 위 계획을 참고 줄로 보여 줬다. 모바일은 '위에서 고르기 기본'으로 연결을 이끈다(R-P14). 한 기간·한 목표에 칸 하나(R-P1)는 그대로 두고 체험 모드에서 강조한다. (2026-10-05) 칸 안의 세부 목표는 여러 개 가능(R-P17).

## PC를 모바일 기준에 맞춤 (2026-10-03)

기획 요청: "모바일 버전을 기준으로, 데스크톱 화면에 없거나 충돌하는 기능을 고쳐 줘."

| 차이 | PC에서 이렇게 | 근거 |
|---|---|---|
| D-day가 PC에 없음 | 목표 설정에서 정하고(목표 기한에서 고르기), 사이드바 꿈 카드 위에 표시 | R-S10, 기획 결정 |
| 시작하기 단계가 다름 | 체험 → 꿈 → 첫 목표 → 세부목표 → 이번 주 실천 (첫 기록은 휴대폰에서만이라 뺌) | 기획 결정 |
| PC엔 체험 모드 없음 | PC용 체험(`/tutorial`): 진짜 표처럼 빈 칸 클릭·↓ 늘리기·위에서 고르기, 기록은 안내만, 저장 안 됨 | 기획 결정 |
| 위에서 고르기·'계획 밖'이 PC에 없음 | 월간·주간 팝오버도 위 계획 먼저, 나머지는 '계획 밖에서 고르기', 표에 '계획 밖' | R-P14 |
| 휴대폰엔 '표에 올리기/숨기기'가 없어 휴대폰 계획이 PC 표에서 안 보일 수 있음 | 그 기간에 계획이 있으면 열로 보임('표 밖' 표시) | R-G10 |
| 빈 칸을 눌러 바로 넣기 | PC는 그대로 (휴대폰만 '+ 계획' 버튼) | 기획 결정 |
| 기간을 달·해 넘겨 고르기 | PC는 그 달·해 안에서 ↓로 늘리기 그대로. 휴대폰이 나눠 저장한 칸은 달·해마다 따로 보임 | R-P15 |

같은 이름으로 두고 그대로 쓰는 것: 진척도·누적 시간(PC는 트래킹 화면), 회고(PC는 회고 모음), 설정(PC는 계정 관리).

## 만드는 순서

1. **뼈대**: 새 시트(뒤로 가기로 닫힘, 아래에서 올라옴), 앱바·계획/기록 전환, 탭, 밀려 들어오는 화면, 주소 연결
2. **목표**: 목표 탭, 새 목표, 목표 편집(진척도·세부목표·특성·누적), 카테고리, 꿈, 마무리·회고 시트
3. **일정**: 연간·월간·주간 줄, 필터, 계획 칸·실천·참고사항 시트, 지난 기간 잠금
4. **기록**: 오늘(기존 하루 플래너를 새 틀에), 돌아보기
5. **계정**: 계정 시트, 설정 화면, 첫 화면·로그인·가입
6. **다듬기**: 빈 상태, 다크 모드, E2E, 문서
